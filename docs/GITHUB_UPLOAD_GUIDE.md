# GitHub Upload Guide

Recommended repository name:

```text
dolaegis-ai-fraud-detection
```

Recommended description:

```text
Python/FastAPI prototype for explainable SMB e-commerce fraud-risk scoring, dashboarding, and audit-ready decision reporting.
```

Recommended visibility:

```text
Public
```

## Create the repo

Create an empty GitHub repository. When GitHub asks about setup files, choose:

```text
Add README: No
Add .gitignore: No
Choose a license: No
```

This package already includes `README.md`, `.gitignore`, and `LICENSE`.

## Upload contents

Upload the contents of this folder, not the folder itself. The top level should show:

```text
README.md
LICENSE
CHANGELOG.md
Makefile
requirements.txt
.gitignore
.github/
api-examples/
config/
data/
docs/
reports/
src/
tests/
```

## Settings

Suggested repository settings:

```text
Issues: On
Projects: Off
Wiki: Off
Discussions: Off
Actions: On
Default branch: main
```

## After upload

1. Open the repo in an incognito/private browser window.
2. Confirm the README renders correctly.
3. Click the Actions tab.
4. Confirm the test workflow passes.
5. Pin the repo on your GitHub profile.
6. Add the repo link to your resume only after Actions passes.
