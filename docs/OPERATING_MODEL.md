# Operating Model

DolAegis is positioned as an SMB-first fraud-prevention SaaS. The operating model should align product, engineering, security, support, and governance around measurable fraud reduction and trustworthy automation.

## Roles

| Role | Responsibility |
|---|---|
| Product owner | Roadmap, merchant workflows, prioritization |
| Engineering | API, dashboard, data pipeline, integrations |
| Security lead | access controls, monitoring, secure SDLC |
| Risk analyst | fraud patterns, rule tuning, manual-review policy |
| Customer success | onboarding, support, merchant feedback |
| Governance review | compliance evidence, model/rule changes, audit readiness |

## Key metrics

- Fraud losses prevented
- Chargeback reduction percentage
- False positive rate
- Manual review volume
- API latency
- Uptime
- Time to integrate
- Merchant satisfaction / NPS
- Appeal or override rate

## Review cadence

- Weekly engineering/product prioritization
- Monthly risk and compliance review
- Quarterly model/rule effectiveness review
- Incident review after outages, data issues, or major false-positive events
